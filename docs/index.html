Designed for real communities

Interactive without being invasive.

Members answer with Discord buttons. The bot never needs Message Content, Server Members, or Presence privileged intents, and it asks only for the channel permissions required to post and update quizzes.

RANDOMIZED

Four challenges a day

Each launch waits a randomized four-to-eight-hour interval, with an initial deployment jitter to avoid predictable posting patterns.

AI-RESISTANT

Scenario-driven prompts

Generated values, shuffled choices, short windows, one-shot answers, and evidence-based scenarios make simple answer-key lookup less useful.

PRIVATE BY DESIGN

No chat surveillance

Selections are submitted as signed Discord interactions. Ordinary messages, DMs, presence, voice, email, and connections are not collected.

BROAD COVERAGE

Eleven technical tracks

Security, networking, backend, frontend, programming, AI, operating systems, Bash, blue team, red team, and mitigation.

COMPETITIVE

XP and random drops

Every answer earns XP. Correct answers can unlock occasional named bonus drops, while profiles and a community leaderboard recognize consistent learning.

ACCOUNTABLE

Learning and response

Topic-routed daily bytes, CISA exploited-vulnerability alerts, respectful AI fact checks, and a private suspicious-contact review queue support the whole community.

Question lifecycle

One answer. No spoilers.

A member's first selection is locked. The bot acknowledges it privately but does not reveal correctness until the shared quiz closes. It then publishes the answer and explanation, updates statistics, and writes the staff result.
