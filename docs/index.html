The toolkit, and what it will not do.

Every reconnaissance tool below reads public third-party records — certificate transparency logs, RDAP registries, DNS. None of them connect to, scan, or probe a host you name. Use them on infrastructure you own or are authorized to assess.

CALCULATORS

Work offline of everything

/subnet gives the full IPv4 breakdown and gets /31 and /32 right. /encode converts base64, hex, and URL both ways. /hash produces SHA-256/384/512 for checking a download against its published checksum. Pure computation, so an upstream outage cannot break them.

PASSIVE RECON

Look without touching

/cert-search finds subdomains in certificate transparency logs. /domain-info returns registrar and expiry via RDAP — a very new registration is a phishing signal. Plus /dns-lookup, /ip-lookup, and /url-check against malware filtering.

PRACTICE SHELL

A Linux box you cannot break

/terminal gives you a simulated machine with a real command interpreter — ls, grep, find, pipes, redirection. It is a simulation, so there is no host to escape to and nothing to damage. The starting image hides a set-uid binary, a world-writable directory, and a committed credential. Find all three.

CONTRIBUTOR

The convenience layer

/email-security grades SPF, DMARC, and MTA-STS. /attack-surface combines CT, RDAP, mail posture, DNS, and reputation into one review. /bulk-url-check takes eight URLs at once. Everything above stays free for every member, permanently.

How the server works

Interactive, and honest about it.

Members answer with Discord buttons. The bot never uses the Server Members or Presence privileged intents. Its conversational companion does read the general channel — that is written down in the Privacy Policy rather than buried, it stores none of that text, and server staff can switch it off.

RANDOMIZED

Four challenges a day

Each launch waits a randomized five-and-a-half to six-and-a-half hour interval, with an initial deployment jitter to avoid predictable posting patterns.

AI-RESISTANT

Scenario-driven prompts

Generated values, shuffled choices, short windows, one-shot answers, and evidence-based scenarios make simple answer-key lookup less useful.

SCOPED, NOT SECRET

One channel, written down

The companion reads the general channel and stores none of it. No other channel, no DMs, no presence, no voice, no email, no connections. The Privacy Policy spells out exactly what is read and how to opt out.

BROAD COVERAGE

Eleven technical tracks

Security, networking, backend, frontend, programming, AI, operating systems, Bash, blue team, red team, and mitigation.

COMPETITIVE

XP and random drops

Every answer earns XP. Correct answers can unlock occasional named bonus drops, while profiles and a community leaderboard recognize consistent learning.

ACCOUNTABLE

Learning and response

Topic-routed daily bytes, CISA exploited-vulnerability alerts, respectful AI fact checks, and a private suspicious-contact review queue support the whole community.

LIVE TOOLKIT

Passive security context

RDAP IP registration, encrypted DNS lookups, malware-filter URL checks, and disclosed aggregate links run directly from Discord.

DYNAMIC CTF

Question lifecycle

One answer. No spoilers.

A member's first selection is locked. The bot acknowledges it privately but does not reveal correctness until the shared quiz closes. It then publishes the answer and explanation, updates statistics, and writes the staff result.
