Hack Theory // Discord application

Sixty commands. No chat reading.

NullPointer Exception Handler turns a Discord server into a structured learning environment — timed quizzes, per-member CTFs, a simulated Linux box, passive security tooling, published courses, and real IT tasks reviewed by staff.

It runs entirely on Cloudflare Workers, holds no Gateway connection, and requests no privileged intents.

Permission transparency

Purpose-built access, not Administrator.

Discord delivers interactions either through a Gateway connection or an outgoing HTTP webhook — never both. This bot uses the webhook path, so there is no socket sitting in your server consuming events. Everything it does starts from a signed interaction you initiated.

INTERACTIONS

Signed requests only

Slash commands and buttons arrive as Discord-signed HTTP requests. Every payload is verified before the Worker acts on it.

PRIVACY

No privileged intents

Message Content, Server Members, and Presence stay disabled. Ordinary chat and private DMs are never read or stored.

DISCLOSED

One documented exception

The optional conversational companion reads a single general channel, stores none of it, and can be switched off by staff. It is written down in the Privacy Policy rather than buried.

SECURITY

Owner-gated servers

The install does not request Administrator. Each server is approved individually by the bot owner — until yours is enabled the commands stay inactive.

What it does

Nine systems, one application.

QUIZZES

Randomized and timed

Roughly four challenges a day on a randomized interval, drawn from reviewed questions plus procedural generators. First answer locks; correctness stays private until the quiz closes.

PRACTICE SHELL

A box you cannot break

/terminal and /sh give you a simulated Linux machine with a real interpreter — pipes, redirection, grep, find. Three planted weaknesses are waiting in the starting image.

DYNAMIC CTF

Per-member flags

Challenges randomize per session and flags are signed to the solver, so a copied flag will not validate as someone else's solve. /ctf-stats tracks the live board.

PASSIVE RECON

Look without touching

Certificate transparency, RDAP, DNS-over-HTTPS, and malware filtering. Nothing connects to, scans, or probes a host you name.

COURSE PORTAL

Publish and browse

/teach opens an upload portal that publishes a structured course to the academy channels, with labs, assessments, and safe-use boundaries.

ASSIGNED WORK

Real IT tasks

Staff assign a randomized task; the member submits it and answers five follow-up questions, which staff review through /task-report.

MODERATION

Notices and review

Warning and information notices, member moderation views, staff polls that escalate on a majority, and a private queue for suspicious-contact reports.

ALERTING

CISA KEV watch

The known-exploited-vulnerability catalog is polled hourly and routed to the server, alongside topic-routed daily learning material.

OPT-IN AI

Tutor and fact checker

/ask answers technical questions privately by default. /fact-check evaluates a claim respectfully rather than dunking on whoever made it.

Before installation

Know what will happen.

  1. Discord opens its official authorization screen for application 1306605317676859392.
  2. Discord displays the exact permissions being requested, for your review.
  3. Administrator is not among them, and no privileged intents are enabled.
  4. After install, the commands stay inactive until the bot owner approves your server.
  5. Request approval in Hack Theory with the server ID the bot reports back to you.
